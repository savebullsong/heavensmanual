# Heaven's Manual

현실·천국·지옥 세 세계를 오가는 현실 배경 2D 도트 웹 MMO. 기획 기준 문서는 「Heaven's Manual 통합 기획서 v1」입니다.

## 지금 상태: 1단계 완료 · 2단계 지옥 1~3층 · 3단계 천국 시작 · 11월 24일 14차 개정 (무기 든 괴물, 2층 탈루스, 새 지옥 바닥·흐르는 용암, 넓어진 1층, 길잡이 화살표, 건물 도트 교체)

### 그래픽: 3D 모델 → 도트 렌더링 (tools/sprite3d)

- 캐릭터: Blender 인형(남·여 × 체형 3 + 아이)을 같은 30도 등각 카메라로 4방향 렌더 → 몸·머리카락·무기 층을 따로 굽고, 게임에서 색을 입혀 합친 뒤 외곽선을 두른다
  - 동작: 서 있기 1, 걷기 8, 맨손 공격 4, 무기 휘두르기 6, 권총 3, 맞음 2, 쓰러짐 4
  - 차림 5 (평상복·앞치마·우비·환자복·앵무새 옷), 머리 모양 6, 무기 9 (쇠파이프·장도리·식칼·삽·야구 배트·손도끼·단검·장검·권총)
  - 한 픽셀 = 구역 번호 × 16 + 음영 단계 (PNG 회색+투명). 피부·머리·윗옷·바지 색은 게임에서 바꾼다
- 거리: 건물 면 조각(1층 7종·위층 6종·옥상 난간 2종 × 왼쪽/오른쪽 면)을 OSM 건물 크기에 맞춰 조립. 건물마다 벽색·차양색, 밤에는 창문 불빛을 따로 입힌다. 가게 이름 간판은 1층 처마 띠에 붙인다
- 바닥 타일(보도 블록·아스팔트·골목·공원·물 등 4종씩), 차 11종(택시 분홍·초록, 승용차, 픽업, 툭툭, 오토바이 택시, 버스), 나무·가로등·BTS 기둥·노점 수레·옥상 설비
- 우주새 상점 안: 방(낮·밤), 카운터, 유황앵무(볏 내림·세움), 매달린 등을 한 장면으로 렌더
- 플레이어를 가리는 건물은 통째로 반투명
- 다시 굽기: `python3 tools/sprite3d/bake_all.py <출력> --scale2` (캐릭터 2배, 2코어 약 3시간 · 번호나 태그로 일부만: `... --scale2 hell`) · `street.py <출력폴더>` · `shop.py <출력폴더>` (Blender는 `pip install bpy`)


### 14차 개정 (11월 24일) — 무기 든 괴물, 탈루스, 지옥 바닥, 넓은 1층, 길잡이
- 지옥 괴물은 모두 무기를 든다 (거대한 층주 구르마만 맨손): 잿빛 망자 곡괭이 · 불씨 망자 달아오른 낙인 쇠 · 늪 망자 쇠갈고리 장대 · 흥정꾼 망자 고기 칼 · 프렛 바닥 뚫린 국자 · 피 프렛 살덩이 꼬챙이 · 걷는 해골 거인의 넓적다리뼈 · 빚진 해골 빚 갈고리 · 야크 몽둥이. 쇠는 녹슨 쇳빛(층주만 금빛)
  - 3D로 굽기: 망자·프렛·해골 몸의 무기 자세(m) + 무기 층 (`bake_all.py ... --scale2 armed`)
- 2층 들판의 노름꾼 탈루스(Talus): 챙 넓은 모자·기운 가죽 외투·해골 손·붉은 목수건·산탄 띠, 쌍대 산탄총 (`--scale2 talus`)
  - 뼈주사위 두 개의 합 홀/짝에 노전 5·10·25닢을 건다. 맞히면 건 만큼 더, 틀리면 잃는다 (주사위 구르는 소리)
  - 불고기맛 과자 3닢 (가방에 들어감, 체력 35 회복 · 탈루스만 판다)
  - 악마(괴물)가 7칸 안에 오면 산탄총 한 방에 쓰러뜨린다 (내가 깎아 둔 괴물이면 영격·노전 나눔, 바로 다시 채움). 탈루스는 칠 수 없다. 주변 14칸에는 괴물이 나지 않는다
  - 자리: 마을과 내려가는 구덩이 사이 들판의 다진 흙터, 노름판(뒤집은 나무 상자·뼈주사위·노전·과자 봉지·뼈 걸상), 작은 모닥불
- 지옥 바닥을 새로: 칸마다 같은 마름모를 찍던 방식 대신 점마다 둘레 네 칸을 섞어 경계를 구불구불하게, 칸을 넘어 이어지는 무늬(재 언덕·갈라진 금·자갈·그을린 모래, 진흙의 젖은 빛·물웅덩이·풀, 붉은 흙·핏자국), 왼쪽 위 빛의 높낮이 그림자, 돌길은 모서리가 빛나는 돌, 늪길은 널빤지
  - 용암: 식은 껍질 조각 사이의 달아오른 금, 뜨거운 웅덩이, 가장자리의 빛나는 테, 둘레의 그을린 땅. 위로 흘러가는 빛줄기와 부풀어 터지는 거품(움직임). 늪은 느린 물결, 핏물은 흐르는 결과 거품
- 1층(재의 문턱)을 1.6배로 넓힘 (104칸 → 166칸, 괴물 22마리). 층을 늘리기 전에 한 층을 넓게
- 같은 지형지물이 되풀이되지 않게: 나무·바위·땅 자국 24가지, 해골 더미·꼬챙이·철창·가마솥 12가지, 내장 더미는 층마다 2~3개, 시체·뼈 무더기·고문 장면·가마솥 수를 줄이고 서로 멀리
- 고문하던 야크를 누르면 고문을 멈추고 덤빈다 (진짜 괴물이 되어 싸움, 망자는 남는다)
- 길잡이: 화면 밖에 있을 때 가장자리에 화살표와 글자 — 위층 계단(잠김 표시) · 층주 · 아래층 구덩이. 누르면 그쪽으로 걷는다. 층주를 못 쓰러뜨린 층에 들어오면 "위층 계단은 층주를 쓰러뜨려야 열립니다" 한 번 안내
- 관리자 '도트 그림'에 건물 칸: 우주새 낮 · 우주새 밤 · 베스크 대부소. 지금 그림(1배)·2배 밑그림 내려받기, 같은 크기나 2배 PNG만 올림. 게임은 올린 그림으로 건물을 세운다 (2배면 반으로 줄여 섬세하게)
- 갑옷: 환자복·우비·앵무새 옷 차림이라도 재킷·조끼·작업 바지를 입으면 그 옷 대신 방어구가 보인다 (예전엔 옷에 가려 계속 환자복)
- 경비병·탈루스가 마무리한 몹의 알림은 "함께 잡음 N%"
- 관리자 지옥 층 이동: 영혼 설정 '관리자 캐릭터'에 1·2·3층 단추 → 그 층 휴식 마을로 바로 (지도 확인용). 지옥 밖(현실·천국·귀신)에서 왔으면 '현실로 돌아가기' 단추로 돌아간다 — 환생이 아니라 시찰에서 돌아오는 것이라 몸·돈·업은 그대로. 투명 상태는 층을 옮겨도 유지

### 13차 개정 (11월 24일) — 휴식 마을 경비병, 영격 나눔, 우주새 입체 창
- 경비병(「지옥 13층 경비병 설정집」 B01~B03): 층주의 휴전 협약에 따라 휴식 마을을 지키는 중립 NPC, 마을마다 둘이 네 문을 나눠 순찰 (마을 가운데 ↔ 문 안쪽)
  - 1층 재문지기(Ash Warden): 재 묻은 해골·회색 망토·문고리 뼈 곤봉·돌문 열쇠. 곤봉을 내려쳐 크게 밀어낸다 (먼지 고리). "이 문 앞에서는 더 이상 누구도 다치지 않는다."
  - 2층 빈그릇귀(Hollow Bowl): 갈비뼈가 휜 빈 배·팔에 진흙 사발. 진흙 파문으로 비틀거리게 하고 2.6초 느리게. "굶주림은 핑계가 될 수 없다."
  - 3층 봉랍귀(Waxseal): 붉은 밀랍 얼굴·검은 상인복·인장 지팡이. 붉은 봉인 낙인 5초 (낙인 찍힌 쪽은 주는 피해 절반, 경비병에게 1.5배로 맞음). "서명은 자유다. 칼은 아니다."
  - 순찰 → 감지 → 개입 → 복귀: 마을과 둘레(울타리 밖 6칸)에 들어온 괴물을 잡고, 둘레 10칸 밖으로는 쫓지 않는다
  - 사람: 둘레에서 다른 영혼을 치거나 경비병을 치면, 가까운 경비병이 1초 경고 뒤 제압. 사람은 죽이지 않고 체력 1까지 (한 대에 최대 체력의 12%쯤) → 마을 둘레 밖으로 내던짐. 마지막 싸움 뒤 3초면 적대가 풀린다
  - 괴물보다 강하다 (체력 1600/2000/2400). 쓰러뜨려도 보상·카르마·영격 없음, 25초 뒤 자리로 돌아온다
  - 3D로 굽기: monster 'g'(해골 망토)·'o'(빈 배)·'w'(밀랍 상인), 무기 knocker·sealstaff (`bake_all.py ... --scale2 guard`)
- 영격 나눔: 내가 싸우던 괴물을 경비병이 마무리하면, 내가 준 피해 비율(25~80%)만큼 영격과 노전을 받는다 ("경비병과 함께 잡음 50%") — applyDeed의 share
- 리젠 보충: 경비병이 잡은 괴물은 1.2초 만에 사라지고 같은 수가 바로 마을 둘레 밖 들판에 다시 선다. 새 괴물은 마을 둘레 8칸 안에서는 나지 않는다
- 우주새 창 입체감: 창마다 벽 속으로 파인 구멍(안쪽 설주·창턱이 보임), 깊이만큼 들어간 유리와 그 너머, 위 설주 그림자·유리 반사 두 줄, 벽에 드리운 틀 그림자, 두께 있게 튀어나온 틀
  - 둥근 창: 두꺼운 볏 색 테 + 십자 창살 + 안쪽 횃대의 앵무새 그림자 + 아래 나무 받침
  - 진열창: 튀어나온 창턱과 화분 둘, 벽에서 비스듬히 나온 줄무늬 천 차양(물결 드림·옆 천·받침 쇠·그림자)
  - 유리문은 벽 속으로 들어가고 문턱 발판, 문 위 등은 쇠 팔에 매단 상자 등. 어항 벽은 수조 바닥 모래·물풀, 2층 옆 창은 커튼과 꽃 상자
- 이름표: 네모칸 없이 어두운 테두리 글자만 (싸우는 장면을 가리지 않게)
- 지옥 들판: 길가 화로·등을 모두 없앰 (불빛은 마을 안 모닥불·문 등, 용암, 촛불 해골, 가마솥, 버섯뿐). 마을 밖 집은 몇 채만 남기고 지형과 나무로
  - 지옥 나무: 1층 숯 나무(틈마다 불씨) · 뼈나무(등뼈 줄기·뼈 가지·매달린 해골) / 2층 부푼 썩은 나무(휜 뿌리·입 같은 구멍·이끼·버섯 빛) · 손 덤불(진흙에서 뻗은 마른 팔) / 3층 가시 나무(핏빛 잎·사슬에 매단 동전 추와 값표) · 피 묻은 뼈나무
  - 바위 무더기(현무암 용암 금 · 이끼 바위 · 붉은 사암 핏자국), 땅의 자국(용암 금 · 거품 진흙 · 끌린 핏자국, 밟고 지나감), 1층 용암 웅덩이·3층 핏물 웅덩이
  - 흩어진 뼈는 이제 밟고 지나간다 (예전엔 길을 막았다)
- 베스크 대부소: 베스크는 3층 피의 시장에만 (1·2층에는 없다 — 층마다 고유 인물을 둘 자리). 유황새에서 나와 마을 안 자기 건물로
  - 겉: 검붉은 벽돌·돌 받침·모서리 돌, 벽 속 쇠띠 겹문과 금 징·돌계단, 쇠창살 촛불 창, 동전 더미·장부 그림 판(글자 없음), 붉은 봉랍 독촉장, 검은 슬레이트 지붕·노전 장식·굴뚝, 사슬 동전 추
  - 안: 장부 책상(펼친 장부·깃펜·노전 더미) 뒤의 베스크, 장부 서가, 쇠 금고, 노전 자루, 촛대. 베스크에게 말을 걸면 대출·상환

### 12차 개정 (11월 24일) — 3단계 천국 시작, 약한 적, 지옥의 집과 덩어리
- 천국(3단계): 선이 더 무거운 영혼은 천국으로 (흰 빛 속으로 떠오르는 장면 + 종소리). 수쿰빗 지도를 그대로 쓰되 늘 낮, 밝고 따뜻한 빛, 화면 가장자리의 구름 안개와 흘러가는 구름. 차·불량배 없음
  - 황색날개: 미스 황과 같은 얼굴, 흰 옷·금빛 띠·노란 날개. 상점이 아니라 우주새 둘레를 걸어 다니며 물건을 공짜로 준다 (물·콜라·초콜릿·감자칩·붕대). 미스 황·황혼을 모른다
  - 환생관 루엔: 우주새 문 옆. 언제든 현실로 환생, 쌓은 선행 1점 = 영혼 경험치 10 (HEAVEN_BONUS_PER_GOOD)
  - 천사(흰 날개)와 구원받은 영혼(흰 옷). 그림자 말고 누구에게든 손을 들면 악행 +5, 현실로 강제 환생 (보너스 없음)
  - 천국에서 쓰러지면 잃는 것 없이 루엔 곁에서 깨어남. 우주새는 비어 있다 (황색날개는 거리에)
  - 천국 사람끼리만 보인다 (실시간 채널 분리)
- 잡기 쉬운 적: 현실의 취객(비틀걸음, 체력 70, 약한 주먹, ฿5~30, 선행 +1) · 천국의 그림자(빛을 빼앗으려는 미련, 체력 50, 선행 +1)
- 지옥 건물: 초가집(둥근 짚 지붕·새끼줄 그물·문 위 해골) · 감옥(쇠창살 감방·쥔 손·쇠문·사슬·횃불) · 뼈집(뼈를 쌓은 벽·박힌 해골·상아 엄니 문·가죽 지붕의 갈비뼈·뿔 해골). 그보다 많은 대형 짐승 시체(갈비뼈 아치·썩은 살·뿔 달린 해골·고인 피·파리) · 뼈 무더기 · 내장 더미. 층마다 비율이 다름
- 유황새의 앵무새: 횟대 없이 사람 키로 두 발로 서서 가게 안을 걸어 다닌다 (3D로 굽기: monster 'b', outfit 'cockatoo'). 누르면 멈춰 돌아본다
- 지옥에서 무기를 살 때 '그걸로 뭘 하시려고요'는 빼고 현실에만

- 관리자 `/admin`: 인물 그림(대화창) · 도트 그림(게임 속) 두 메뉴. 도트 칸은 지금 그림을 확대해 보여 주고, 정확한 크기·발 기준점을 알려 주며, 밑그림 내려받기 → 같은 크기 PNG만 받음. 앵무새는 볏 내림·세움 두 칸
- 다시 굽기: 이미 구운 층에 상하좌우만 덧붙이기 `python3 tools/sprite3d/bake_all.py <출력폴더> --dirs8`

### 5차 개정 (11월 23일)

- 실제 가게: OSM 가게 정보(편의점·카페·식당·미용실·철물점·마사지 등 약 90종)를 건물에 붙임. 체인점은 상표 대신 업종 이름, 개인 가게는 실제 이름. 가게가 없는 건물은 눌러도 이름표가 뜨지 않고 뒤의 길로 걸어감
- 일하기: 가게 안으로 들어가 사라지고 위쪽에 '일하는 중'. 아무 데나 누르면 그만두고 나옴
- 거리 가게: 편의점·약국·식당·카페에서 회복 물건 사기 (효과는 숫자 대신 '조금 회복·많이 회복' 같은 말)
- 숫자 숨김: 싸움 피해 숫자, 체력 숫자 없음. 체력 막대로만 짐작
- 영격 창: 힘·민첩·생명력·신앙 (각 1에서 시작, 영격이 오를 때마다 2점). 공격력·방어력은 보이지 않음
- 공격 태세: 오른쪽 아래 칼 단추 1번 = 적대 대상만, 2번 = 모두. 손 단추 = 평소대로 (누르면 메뉴)
- 대식자: 범죄 표시 중이면 바늘과 금실을 든 집행자가 다가옴. 체력이 절반 아래로 떨어지면 실밥이 터진 모습으로 변함
- 방어구가 몸에 보임 (헬멧·재킷·조끼·장갑·작업 바지·정강이 보호대·부츠)
- BTS 고가 상판: 기둥 사이를 잇고, 선로가 휘는 곳은 기울여 매끈하게
- 종교 건물: 이름으로 가려 태국 사원(붉은 2단 지붕)·교회(회색 박공과 종탑)·이슬람 사원(초록 돔과 첨탑)·시크 사원(흰 돔과 금빛 작은 돔)
- 오토바이 택시·자동차 바퀴가 바닥에 눕던 문제 수정 (Blender 변환 행렬이 늦게 갱신되던 것)
- 우주새 진열장 조명 밝게
- 비회원으로 바로 플레이. 오른쪽 위 메뉴 왼쪽의 '이 세상에서 살기로 결정' = 가입 (아이디·비밀번호만, 이메일은 나중에)
- 처음 가게를 나선 뒤 거리에서 5분이 지나면 미스 황의 전화 → 예 = 가입·홈 화면 설치 안내 (`?call` 이면 5초)
- 계정 저장: Supabase (아이디·비밀번호 해시·저장 데이터·프로필·신고). 가입하면 기기 저장을 서버로 옮기고 20초마다·창을 닫을 때 저장
- 실시간: 같은 구역의 다른 플레이어가 보임 (Supabase Realtime presence + broadcast). 다른 플레이어를 누르면 프로필 보기·신고
- 관리자 `/admin`: 미스 황·앵무새의 게임 속 도트 그림 교체 칸 (투명 PNG 그대로 올림, 발 = 그림 아래 가운데)
- 홈 화면 설치(PWA): 그림과 지도는 기기에 남겨 다음부터 빨리 엶

### 1단계-A (입구)


- 리니지 초기 크기: 어른 키 약 40px(아이 약 28px), 3/4 시점 대각선 4방향(좌우 뒤집기), 걷기 4장면. 차는 약 30px, 건물 1층은 사람보다 높게
- 첫 장면은 우주새 상점 안 (거리와 같은 축척). 물건은 카운터 뒤, 미스 황 뒤쪽 진열장에 입체로 진열 (상자·캔·병·봉지·밧줄·헬멧·옷·신발), 무기는 카운터 뒤 벽 걸이판, 마네킹, 창 아래 의자·화분·우산꽂이
- 처음 모습은 무작위: 우비(얼굴 가려짐) · 환자복과 머리 붕대 · 남성 · 여성 · 아이 · 앵무새 옷, 드물게(3%) 광채가 일렁이는 남성·여성
- 미스 황은 처음 모습을 보고 한마디 함. 무기와 방어구는 첫 방문부터 살 수 있음
- 문으로 나가면 "…나는 누구였지." 혼잣말 뒤 이번 생의 모습(성별·체격·피부·헤어·머리색·옷·차림)과 지역(방콕 · 수쿰빗 / 서울 · 강남 준비 중)을 고름. 아이로 왔어도 거리로 나가는 몸은 어른, 광채는 남음
- 거리의 우주새 건물에는 간판이 없음. 건물을 누르면 '우주새 상점' 이름표가 뜨고 걸어 들어감
- 대화: 주요 인물은 일본 RPG식 인물 그림, 혼잣말은 이름표 없이 기울인 글씨
- 관리자 페이지 `/admin`: 주요 인물 7칸 그림 교체 (Vercel Blob)
- 시험용 주소: `?newlife` 새 영혼으로 다시 시작, `?form=raincoat|patient|man|woman|child|parrot|auraMan|auraWoman` 처음 모습 고정, `?hour=21` 시각
- 공용 규칙 코드: 카르마 판정, 행위별 점수표, 영격 곡선(800 × n^1.7), 기적 확률, 위험 상태와 차량 충돌

### 1단계-B (현실 생존) — 이번에 들어간 것

- 걷는 모습: 몸통·다리·팔이 모두 걷는 방향으로 같이 돌아감 (가까운 쪽 크게, 먼 쪽 어둡고 작게)
- 건물 깊이: 건물을 32px 세로 띠로 잘라 띠마다 앞뒤를 따로 계산. 건물 바닥 칸은 못 걸음. 캐릭터가 건물·기둥 뒤에 가려지면 그 부분만 반투명
- 간판: 그냥 '상점' 대신 칸마다 다른 이름 (예: 할머니 잡화점, 골목 약국). 한국어·태국어·영어 각각 어순에 맞게
- 내 캐릭터 표시: 발밑 금색 고리와 머리 위 화살표 (범죄 표시 중엔 빨강)
- 대상 메뉴: 사람을 누르면 말 걸기 · 살펴보기 · 강제 공격, 불량배는 공격하기. Ctrl/Shift/⌘ + 클릭 = 메뉴 없이 강제 공격. 이름 있는 가게는 들어가기·일하기
- 싸움: 체력 막대, 치명타, 쓰러짐. 불량배는 밤에 더 멀리서 덤빔. 행인을 먼저 치면 악행 + 3분간 빨간 표시, 행인은 도망치며 소리침
- 돈: 쓰러진 사람이 떨어뜨린 돈을 주움 (행인 돈을 주우면 강도 악행). 일하기 = 방콕 최저임금 하루 ฿400 ÷ 8시간 = 시급 ฿50, 현실 시간으로 지급
- 차 사고: 차는 사람 앞에서 브레이크. 그래도 치이면 체력 30% 손해, 위험 상태(25% 이하)면 사망
- 죽음: 사인 → 이번 생의 선행·악행 → 판정(천국 / 지옥 n층 / 떠도는 영혼). 천국·지옥 문은 아직 닫혀 있어 우주새에서 새 모습으로 눈뜸. 영격은 유지
- 가방: 먹기·쓰기(체력 회복), 장착·빼기(공격·방어), 권총은 총알이 있을 때만 원거리
- 알림: 선행·악행·영혼 경험치·영격 상승
- 저장: 이 기기(localStorage)에 4초마다

## 실행

```
cd apps/web
npm install
npm run dev            # 개발 서버
npm run check          # 타입 검사
npm run build          # 배포용 빌드 (dist/)
npm run preview-single # 파일 하나짜리 미리보기 (dist-single/index.html)
```

규칙 검증: `node --experimental-strip-types packages/shared/src/rules.test.mjs`
API 확인: `cd apps/web && node --experimental-test-module-mocks --experimental-strip-types --test test/portraits.test.mjs`

관리자 페이지가 그림을 저장하려면 Vercel 프로젝트에 Blob 저장소를 연결하고(환경변수 `BLOB_READ_WRITE_TOKEN`), 환경변수 `ADMIN_PASSWORD`를 넣어야 합니다.

## 실제 수쿰빗 지도 넣기

1. openstreetmap.org 에서 수쿰빗 구간을 화면에 맞춘 뒤 상단의 '내보내기(Export)' → '내보내기' 버튼으로 `.osm` 파일을 받습니다. (아속~프롬퐁 정도의 작은 범위)
2. `node tools/osm-convert/convert.mjs 받은파일.osm apps/web/public/zones/bkk-sukhumvit.json --id bkk-sukhumvit --tile 3`
3. 변환기는 큰길을 가로축에 맞춰 돌리고, 정부시설을 간판 없는 일반 건물로 바꾸고, 지도 가운데 가게 하나를 우주새로 정합니다. 서울 강남은 `--keep-right` (우측통행).

지도 데이터: © OpenStreetMap 기여자, ODbL. 게임 화면과 사이트에 출처를 표기해야 합니다.
