현실·천국·지옥 세 세계를 오가는 현실 배경 2D 도트 웹 MMO. 기획 기준 문서는 「Heaven's Manual 통합 기획서 v1」입니다.

## 지금 상태: 1단계 완료 · 2단계 지옥 1~3층 · 3단계 천국 시작 · 11월 25일 21차 개정 (이동 끊김 줄이기, 거리 정비·차·횡단보도·도시 끝 스모그, 백화점, 장비 창 남녀 몸, 지옥 휴게소 장사꾼·호텔·서큐버스·원거리 무기, 연타 공격, 드랍 돈 폭 넓히기)

### 그래픽: 3D 모델 → 도트 렌더링 (tools/sprite3d)

- 캐릭터: Blender 인형(남·여 × 체형 3 + 아이)을 같은 30도 등각 카메라로 4방향 렌더 → 몸·머리카락·무기 층을 따로 굽고, 게임에서 색을 입혀 합친 뒤 외곽선을 두른다
  - 동작: 서 있기 1, 걷기 8, 맨손 공격 4, 무기 휘두르기 6, 양손 내려찍기 6, 권총 3, 맞음 2, 쓰러짐 4, 앉기 1
  - 차림 5 (평상복·앞치마·우비·환자복·앵무새 옷), 머리 모양 6, 무기 9 (쇠파이프·장도리·식칼·삽·야구 배트·손도끼·단검·장검·권총)
  - 한 픽셀 = 구역 번호 × 16 + 음영 단계 (PNG 회색+투명). 피부·머리·윗옷·바지 색은 게임에서 바꾼다
- 거리: 건물 면 조각(1층 7종·위층 6종·옥상 난간 2종 × 왼쪽/오른쪽 면)을 OSM 건물 크기에 맞춰 조립. 건물마다 벽색·차양색, 밤에는 창문 불빛을 따로 입힌다. 가게 이름 간판은 1층 처마 띠에 붙인다
- 바닥 타일(보도 블록·아스팔트·골목·공원·물 등 4종씩), 차 11종(택시 분홍·초록, 승용차, 픽업, 툭툭, 오토바이 택시, 버스), 나무·가로등·BTS 기둥·노점 수레·옥상 설비
- 우주새 상점 안: 방(낮·밤), 카운터, 유황앵무(볏 내림·세움), 매달린 등을 한 장면으로 렌더
- 플레이어를 가리는 건물은 통째로 반투명
- 다시 굽기: `python3 tools/sprite3d/bake_all.py <출력> --scale2` (캐릭터 2배, 2코어 약 3시간 · 번호나 태그로 일부만: `... --scale2 hell`) · `street.py <출력폴더>` · `shop.py <출력폴더>` (Blender는 `pip install bpy`)


### 38차 개정 (11월 27일) — 내리찍는 칼질과 찌르기, 서울 사계절 옷, 휴대폰 시야, 인물 1.2배, 새 3D 미스 황·천사

- **근접 공격**: 한 손 무기는 머리 위로 크게 들어 올렸다가 발치까지 끝까지 내리긋는다 (여섯 장, 넷째 장이 맞는 순간). 방패는 같이 휘두르지 않고 가슴에 붙여 두었다가, 다 그은 뒤 앞으로 밀어낸다. 칼끝을 따라 초승달 궤적이 남고, 내가 때리면 화면이 살짝 흔들린다
- **찌르기**: 단검·식칼·레이피어는 팔을 뻗어 앞으로 찌른다 (다섯 장, 셋째 장이 맞는 순간, 찌른 방향으로 짧은 빛줄기)
- **서울 사계절 옷**: 반팔은 여름에만. 겨울은 행인 열에 여덟이 무릎까지 오는 패딩(누빔 줄·지퍼·선 깃·부츠), 나머지는 긴소매. 봄은 밝은 긴소매, 가을은 흙빛 긴소매. 깡패·마피아는 검은 패딩. 아이·강도·그림자는 그대로
- **휴대폰 시야**: 터치 화면은 저절로 1.6배(큰 태블릿 1.3배)로 당겨 본다. 영혼 설정 '화면'의 **시야**에서 자동 · 1 · 1.3 · 1.6 · 2배를 고른다
- **인물 1.2배**: 사람·몹·천사·악마(날개·뿔·꼬리·짐 포함)를 1.2배로, 건물·차·땅은 그대로. 체력 막대·머리 위 화살표·말풍선·피해 글자·누르는 범위도 함께 올림. 우주새 가게 안의 미스 황·주인공·앵무새도 (`sprites.ts` BODY_K)
- **미스 황 새 3D 몸**: 흰 블라우스와 리본, 종아리까지 오는 치마, 검은 스타킹과 부츠, 금빛 우주새 수를 놓은 앞치마(주머니·배지·뒤 매듭), 물결치는 긴 머리와 노란 깃털 핀. 지옥의 황혼은 같은 몸에 검붉은 색. 관리자가 올린 도트가 있으면 그것이 먼저 보인다
- **천사 새 3D 몸**: 흰 튜닉과 금테 무릎 치마, 금빛 가슴판·어깨받이·허리띠·보석, 팔 보호대. 남자는 넘긴 짧은 머리, 여자는 높이 묶은 머리. 칼 든 천사는 새 칼질로 싸운다. 택시 천사는 남색 제복
- 굽기: `bake_all.py ... --scale2 swing39 season39 main39` (`poses.py` SWING·STAB, `body.py` casualL·padding, `dreambodies.py` misshwang·angelk)

### 37차 개정 (11월 27일) — 넓은 인도와 서울 대로 정리, 큰길가 철물점, 죽으면 물건은 우리로(현실·지옥 따로), 상점 알림 화살표, 줍기·상호작용 단추, 자동 회복·PC 키, 회복품 대기 시간, 싸움 멈춤 고침, 보관 수수료 다시

- **인도**: 세로·비스듬한 대로(아속 몬뜨리 · 강남대로)도 바깥 차로 한 줄을 보도로, 연석 보도에서 건물 쪽 빈터로 두 칸까지 보도를 넓힘(건물이 선 칸은 그대로). 찻길 한가운데 섬처럼 떠 있던 작은 보도 조각은 찻길로, 비스듬한 찻길 가장자리와 중앙분리대도 계단 대신 비스듬한 선으로, 차선 점선은 두 줄에 하나 — 서울 대로의 깨진 그림 정리
- **철물점**: 우주새에서 멀지 않은 큰길가에 하나씩 (방콕 '신타이 철물점' · 서울 '역삼 철물점'). 안: 뒤 벽 구멍판에 걸린 공구, 페인트 깡통 선반, 목재·파이프 거치대와 사다리, 수리 작업대(바이스 · 그라인더 · 고치던 칼), 나사통 진열대, 밧줄·사슬·호스 감개, 빗자루 통, 빨간 공구함, 계산대 주인. 사기 · 팔기 · 수리. 미스 황에게 길을 물으면 맨 위에 '철물점 · 무기 수리', 끼고 있는 것이 많이 닳았으면 먼저 일러 준다
- **죽으면**: 돈은 떨어뜨리고, 떨구지 않은 물건은 모두 보관 우리로 (꺼낼 때 수수료). 지옥에서 쓰러져도 이제 유황새 우리로. 물건은 제 세계의 우리로 — 지옥 물건은 유황새, 현실 물건은 우주새
- **현실·지옥 물건 따로**: 지옥 물건은 현실·천국에서, 현실 물건은 지옥에서 쓰거나 낄 수 없다 (가방에 '다른 세상 물건'). 검은 마스크·일기장·관리자는 예외
- **보관 수수료**: 싼 물건은 낮게, 비싼 무기는 높게 — ฿100 이하 2% · ฿1,000 4% · ฿10,000 6% · ฿100,000 8% · ฿1,000,000부터 10% (지옥은 값 단위대로 10닢 기준). 최소 ฿1 (물 한 병에 최소 수수료 ₩800이 붙던 것)
- **상점 알림 화살표**: 은행 지붕에 늘 떠 있던 간판 대신, 모든 가게 문 가까이(6칸) 가면 문 위에 이름과 아래 화살표가 3초쯤 떴다 사라진다. 멀리 갔다 다시 오면 또. 출입 아이콘이 뜨면 감춘다. 영혼 설정 '화면'에서 켜고 끈다
- **오른쪽 아래 단추**: '1층으로 줄이기'는 영혼 설정 '화면'으로 옮기고 그 자리는 **줍기**(팔 닿는 곳은 바로, 3.5칸 안이면 걸어가 줍는다). 손 단추는 **돋보기 · 상호작용**
- **영혼 설정**: 자동 반격 아래 **자동 회복 사용**과 % (20~60) — 체력이 그만큼 떨어지면 빠른 칸의 회복품을 먹는다. **PC 키** (PC에서만 보임): F1 상호작용 · F2 공격 태세 바꾸기 · F3 회복품 · F4 줍기, 눌러서 바꾸고 겹치면 서로 바꾼다
- **회복품 대기 시간**: 한 번 쓰면 1초 뒤에 다시 (빠른 칸에 어둠이 걷히는 표시)
- **싸우다 둘 다 멈추던 것**: 같은 칸의 반대 귀퉁이처럼 길 찾기가 빈 길을 주는 거리에서 서로 사거리 밖이라 멈춰 서던 것 — 곧장 몇 걸음 다가가 다시 싸운다
- 상점 수량 단추: ×10을 한 번 더 누르면 20 (처음 누른 뒤엔 '+10'으로 보인다)

### 36차 개정 (11월 27일) — 집은 한 곳(유내는 회상으로), 서큐버스·아큐버스 새 몸, 천국 침대·바닥·건물·은행, 영감 안경, 선업은 돈으로, 보관 수수료, 팔 때 수량, 서울 은행 저금

- 내 집: 늘 같은 집 하나 (옷장·선반·냉장고·TV·낮은 상·이부자리·거울·화분). 들어갈 때 4할쯤 놀이터·미용실·진료실 가운데 한 곳이 회상으로 떠오른다 — 빛바랜 색, 이름표 '회상 · 그곳', 회상을 나오면 지금의 집으로 돌아온다
- 서큐버스 새 3D 몸 (컨셉 그림): 보랏빛 검은 긴 머리, 뒤로 휘어 감긴 뿔, 붉은 눈, 어깨를 드러낸 검은 레이스 코르셋·나팔 소매·초커와 붉은 보석, 바닥까지 끌리는 진홍 치마 위로 앞이 트인 검은 레이스 겉치마, 허리에 늘어진 사슬. 등에는 뼈와 발톱이 선 박쥐 날개, 허리 뒤로 스페이드 꼬리. 층마다 빛깔만 다르다 (1층 컨셉 그대로 · 2층 포도주빛 · 3층 붉은 비단과 금사슬 · 4층 베르카 쇳빛 머리와 그을린 가죽)
- 아큐버스 새 3D 몸 (컨셉 그림): 은빛 긴 머리, 머리 위 금빛 고리, 금실 무늬 흰 드레스(목선·허리띠·앞자락 덩굴·밑단)와 별 브로치, 작은 흰 깃털 날개. 남자는 금 영대를 건 흰 긴 옷. 치맛자락은 걸을 때 다리를 따라 밀리고 보폭은 줄였다 (`bake_all.py ... --scale2 dream37`, `tools/sprite3d/dreambodies.py`)
- 천국 길가 침대: 침대마다 꼭 한 사람, 매트리스 한가운데 · 침대끼리 한 칸 띄우고 침대 칸은 막음
- 천국 바닥: 네모 칸이 보이던 것을 둥글게 번지는 결로 (잔디 풀포기·꽃, 대리석 결, 물 반짝임, 길 가장자리 금빛) · 구름 테라스 바닥도 구름 결
- 천국 건물·은행에 들어갈 수 있다 (전엔 음식 권하기만 떴다)
- 영감 안경: 머리 꼭대기의 검은 띠로 보이던 것을 눈 높이의 가는 금테로
- 환생 상담: 선업으로 물건을 사던 것은 없애고, 선업만큼의 돈을 환생할 도시의 돈으로 (선업 1 = ฿50 · 서울 ₩2,000, 현실에서 선업 1을 쌓는 데 드는 돈의 1/10). 도시는 대화 선택지로 묻는다 (악행 100%면 정해진 도시를 알려 준다)
- 보관 우리에서 꺼낼 때 수수료: 물건 하나하나가 아니라 꺼내는 값 합계의 1할, 최소 ฿20(지옥 2닢)은 한 번만
- 팔 때 목록: 입고 있는 것은 수량에서 빼고, 남는 게 없으면 목록에서 뺀다
- 서울 은행: 원으로 적은 금액을 바트 지갑과 견줘 '지갑이 비어 있다'고 하던 것 — 원을 바트로 바꿔 맡기고 찾는다

### 35차 개정 (11월 27일) — 조작 다시 짜기(손·칼·말풍선·W·A·S·D), 휴대폰 유령 누르기 막기, 베스크 대부소 바로잡기

- 휴대폰 유령 누르기: 손가락을 뗀 뒤 같은 자리로 한 번 더 오는 '클릭'이, 그 사이 새로 뜬 선택지·메뉴를 누르던 것 (베스크 '1000닢 빌리기'가 저절로 눌려 빚 2000). 단추는 손가락이 그 단추 위에서 눌렸을 때만 눌린 것으로, 선택지는 뜬 뒤 0.35초 동안 받지 않는다
- 베스크 대화에 ✕, ✕로 그만두면 빌리지도 갚지도 않는다 (전엔 −1이 들어가 값이 깨질 수 있었다) · 미스 황 길 묻기·천국 음식 권하기도 같은 구멍 막음
- ✋ 손 태세: 사람을 누르면 이름이 뜨고 곁으로 걸어가기만 한다. 곁(1.9칸)에 서면 말을 걸 수 있는 사람 머리 위에 말풍선 — 그걸 눌러야 말을 건다. 같은 사람을 곁에서 한 번 더 누르면 살펴보기·강제 공격 메뉴
- ⚔ 칼 태세: 적은 누르면 공격, 중립은 누르면 그 곁으로 걷기만 (메뉴·공격 없음). 손가락 빗나감 보정은 적에게만
- 지옥 고문하던 괴물은 칼 태세에서 몸을 정확히 눌렀을 때만 덤빈다 (걷다가 싸움이 붙던 것)

### 18차 개정 (11월 25일) — 수쿰빗 다섯 구역, 천국의 테라스, 거리의 삶

### 17차 개정 (11월 25일) — 지옥 땅과 마을, 전투 규칙, 거리의 적
- 버그: 흑철 대검이 끼워지지 않던 것 (장착 칸을 물건 종류에서 바로 정한다 — 새 무기가 빠지지 않게)
- '적대만 공격' 태세에서 경비병은 칼 모양 커서가 뜨지 않는다 (나를 공격했을 때만 적). 깨어 있는 괴물은 적
- 무기에 공격력, 방어구에 방어력 숫자 표시 (가방·상점)
- 방어력 = 회피 (D&D식): 공격하는 쪽이 d20 + 명중 보너스를 굴려 회피 등급(10 + 방어력 합 ÷ 2 + 민첩 ÷ 5) 이상이면 맞는다. 1은 늘 빗나가고 20은 늘 맞는다. 맞으면 피해는 무작위 그대로 (피해 감소 물건만 줄인다 — 아직 없음)
  - 명중 보너스: 취객·그림자 +1 · 불량배 +3 · 강도 +5 · 마피아 +7 · 지옥 괴물 +3+층 · 층주 +9 · 대식자 +8 · 경비병 +10 · 다른 사람 +4
- 활(사냥 활 ฿3,200 · 화살 20대 ฿150, 우주새): 쏘는 자세에서 세로로 선 활대·메긴 화살. 원거리(권총·활)는 민첩 × 1.5가 공격력에 더해진다 (근접은 힘)
- 거리의 적: 취객 < 불량배(체력 150, 취객 다음 약함) < 강도(320, 복면·후드·더플백, 식칼·쇠파이프·손도끼·배트) < 마피아(520, 정장·붉은 넥타이·금줄·선글라스, 권총은 멀리서 쏜다). 강도·마피아도 여자가 있다 (같은 이름). 저마다 시비·요구·포기 대사
- 선행·악행: 아주 조금씩 쌓인다 (점수표 × 0.2, 소수 첫째 자리). 이번 생과 모든 생을 따로 기록하고 영격 창에서만 보인다 (가방 머리말에서 뺌). 천국·지옥 심판은 이번 생으로
- 현실 돈: 취객·불량배 ฿1~2 · 강도 ฿2~4 · 마피아 ฿3~5. 행인(중립)은 ฿1~300 — 대개 ฿1~3, 가끔 수십, 아주 드물게 ฿150~300
- 관리자: 영혼 설정에 '천국으로' (돌아가기는 시찰 전 세계로)
- 상인마다 다른 무기: 우주새 = 손도끼·단검·장검·소방 도끼·권총·활 / 철물점·수리점 = 쇠파이프·장도리·삽·오함마 / 백화점·쇼핑몰 = 식칼·야구 배트 / 지옥 고깃간 = 푸줏간 고기 칼 / 넝마장수 = 넓적다리뼈 몽둥이·망자의 곡괭이·빚 갈고리 (+헌 방어구 둘). 유황새와 겹치지 않는다
- 지옥 땅: 사각형 대신 들쭉날쭉한 해안선 — 1층 용암 바다와 현무암 절벽 · 2층 늪물 너머 안개 낀 바위산 · 3층 피의 용암 바다. 들판은 산등성이(1층 현무암 능선 · 2층 깊은 늪 물길 · 3층 무너진 시장 담)로 골짜기가 나뉘고 길만 고개로 지나간다. 걸어서 못 가는 땅은 고개를 뚫어 잇는다
- 지옥 건물마다 층의 흔적 (유황새·은행·회당·대부소·좌판·감옥·뼈집·불탄 도시): 1층 지붕·처마에 쌓인 화산재와 재 가루·밑동 재 더미 · 2층 무릎까지 찬 진흙 띠와 튄 진흙·이끼 덩어리·물때 · 3층 핏빛 벽·흘러내린 핏자국·처마의 붉은 종이 등롱
- 지옥 은행 문을 새로: 돌 아치 문틀(쐐기돌·이음매) 안 쇠띠 두 짝 나무문, 가운데 틈의 등불 빛, 쇠고리, 반쯤 올린 쇠살문 이빨, 문 양옆 돌화로(층마다 불빛 색)
- 마을에서 들어갈 수 없는 집(초가집)을 없애고 층마다 다른 조형물: 1층 재의 악마상(무릎 꿇은 뿔 달린 악마, 불씨 눈, 공물 그릇, 화로 — 영혼들이 엎드려 빌고 중얼거린다) · 2층 굶주린 아가리(늪에 반쯤 잠긴 거대한 돌 얼굴, 빈 그릇) · 3층 피의 저울(심장과 노전을 다는 저울, 늘 노전 쪽으로 기운다)
  - 층마다 마을 사람도 다르다: 1층 비는 영혼 · 2층 굶어 누운 영혼(고깃간이 없다) · 3층 서서 흥정하는 영혼

### 16차 개정 (11월 24일) — 층마다 다른 지옥, 지옥 로비, 경제와 가방

  - 2층 층주 구르마에게 먹을 것을 100개 주면 배불러 잠든다 (싸우지 않고 여울을 건넘)

- 가방: 소비품·장비 탭, 소비품 하나를 퀵슬롯(☆)에 — 화면 단추를 누르면 바로 먹는다, 버리기(🗑)

- 몹 위에서는 칼 모양 커서. 우주새 안 출입문을 밖과 같은 남서쪽 문으로. '황혼을 눌러 말 걸기' 설명 없앰

  - 황색날개: 미스 황과 같은 얼굴, 흰 옷·금빛 띠·노란 날개. 상점이 아니라 우주새 둘레를 걸어 다니며 물건을 공짜로 준다 (물·콜라·초콜릿·감자칩·붕대). 미스 황·황혼을 모른다
  - 환생관 루엔: 우주새 문 옆. 언제든 현실로 환생, 쌓은 선행 1점 = 영혼 경험치 10 (HEAVEN_BONUS_PER_GOOD)

### 9차 개정 (11월 24일) — 확장보다 먼저: 내부 시설과 거리의 디테일

- 건물 내부: 들어갈 때만 업종에 맞는 작은 방을 만든다 (내려받는 그림 없음, 한 번에 한 방만 메모리). 사원·교회·모스크·구루드와라·은행·의원·약국·편의점·식당·카페·술집·미용실·마사지·세탁소·호텔 로비·일반 가게 16가지 틀, 같은 건물이면 늘 같은 방

### 8차 개정 (11월 24일) — 2단계 지옥 시작

- 판정이 실제로 갈린다: 악행 비율 > 50% → 지옥 ⌈(r−50)/50×13⌉층 (지금 열린 1~3층까지, 더 깊으면 3층) · 기록 없음·정확히 50% → 귀신 · 50% 미만 → 천국(아직 닫힘, 우주새에서 다시 눈뜸)
- 지옥 층 (104×104칸, 층마다 고정 씨앗으로 만든 지도)
  - 1층 재의 문턱(재·용암 강·다리·무너진 벽) · 2층 굶주림의 늪(물웅덩이·판잣집) · 3층 피의 시장(골목 격자·핏물 도랑·노점)
  - 층마다 휴식처(금빛 원·촛불, 싸움 불가, 괴물 못 들어옴), 올라가는 계단(층주를 쓰러뜨리기 전엔 사슬), 내려가는 구덩이, 유황새
  - 괴물: 망자 3종·프렛 2종·야크 3종 + 층주(1층 아쉬갈·2층 구르마·3층 세라네). 층이 깊을수록 체력·피해가 크다
  - 괴물을 쓰러뜨리면 영혼 경험치 10×층 (층주는 ×6) + 노전(Obol). 지옥에서 다른 영혼을 때리면 악행 → 비율이 더 깊은 층을 가리키면 그 층으로 떨어짐
  - 지옥에서 쓰러지면 들고 있던 노전 절반을 잃고 그 층 휴식처에서 일어남
  - 1층 출구의 파샤르(환생관): 아쉬갈을 쓰러뜨렸으면 현실로 다시 태어나게 해 줌
  - 유황새: 노전으로 지옥 장비(단검·뼈 망치·쇠사슬 창·흑철 검, 투구·조끼·장갑·정강이받이·장화)와 회복품
- 봉인 보관함: 죽으면 가방(장착 포함)이 그 세계의 우주새에 봉인됨 → 같은 세계의 우주새(현실 미스 황 / 지옥 황혼)에서 '되찾기'
- 귀신: 잿빛 세상, 걷기만 (차에 치이지 않음, 사람·가게 못 만짐, 다른 사람에게 안 보임) → 우주새에 들어가면 앵무새가 말을 하고 현실로 환생
- 새로 고침해도 지옥·귀신 상태 그대로 이어짐
- 캐릭터 2배 해상도: 같은 크기, 픽셀은 두 배 (아래 그래픽 참고). 층마다 밀도(`_px`)를 적어 두어 1배·2배 층이 섞여도 맞물림. 공격·맞기·쓰러짐도 상하좌우 4방향이 더해져 싸울 때 8방향으로 바라봄
- 파비콘: 오른쪽으로 들어 펼친 유황앵무 날개 하나

- 높은 건물: 내 둘레의 길을 가리는 앞쪽 건물은 비치고, 비친 건물을 누르면 그 너머 땅으로 감. 오른쪽 아래 '건물 낮추기' 단추 = 모든 건물을 1층(간판 층)만 보이게
- 파비콘: 펼친 날개 하나 (흰 테두리, 노란 속 — 유황앵무)
- 관리자 도트 칸: 같은 크기 또는 2배 크기 PNG를 받음 (2배는 같은 크기로 보이며 고해상도 화면에서 더 섬세). '2배 밑그림' 내려받기

### 6차 개정 (11월 23일)

- 원터치 조작 (목적 고정형): 처음 누른 대상으로 명령을 한 번만 정하고, 다시 누르기 전까지 지나가는 사람·건물은 무시
  - 땅 = 이동 (바닥에 작은 파동) · 사람 = 메뉴 (공격 태세면 바로 공격, 발밑에 붉은 표적)
  - 건물 = 메뉴 없이 손가락 아래 벽 밑동으로 이동. 이름 있는 건물이면 위쪽 지역 이름 자리에 이름이 잠깐 바뀌어 뜸 (다른 건물을 누르면 바뀜)
  - 상호작용은 가까이 가야만: 가게 문 앞에 멈춰 서면 문 위에 출입 아이콘 → 아이콘을 눌러 들어가기·일하기 (하나뿐이면 바로)
  - 길게 누르기(0.25초) = 무조건 이동, 누른 채 움직이면 목적지가 따라옴 (PC도 마우스를 누르고 있으면 계속 걸음)
  - 말 걸러 가는 중이면 그 사람 머리 위에 말풍선
- 8방향: 위·아래·왼쪽·오른쪽으로 걸을 때 그쪽을 봄 (상하좌우는 서기·걷기만 새로 굽고, 공격·맞음·쓰러짐은 가까운 대각선). 앞으로 갈 두세 칸의 평균으로 방향을 정해 지그재그 길에서도 떨리지 않음
- 효과음: 파일 없이 그 자리에서 합성 (휘두르는 바람, 맨손·둔기·칼날 타격, 치명타, 총소리, 쓰러짐). 멀면 작게, 좌우로 나뉨. 위쪽 스피커 단추로 켜고 끔
- 모바일 상단: 첫 줄 = 시각·체력·돈·영격·가방·소리·언어, 둘째 줄 = 지역(누른 건물·일하는 중) | 살기로 결정
- 관리자 `/admin`: 인물 그림(대화창) · 도트 그림(게임 속) 두 메뉴. 도트 칸은 지금 그림을 확대해 보여 주고, 정확한 크기·발 기준점을 알려 주며, 밑그림 내려받기 → 같은 크기 PNG만 받음. 앵무새는 볏 내림·세움 두 칸
- 다시 굽기: 이미 구운 층에 상하좌우만 덧붙이기 `python3 tools/sprite3d/bake_all.py <출력폴더> --dirs8`

### 5차 개정 (11월 23일)

- 실제 가게: OSM 가게 정보(편의점·카페·식당·미용실·철물점·마사지 등 약 90종)를 건물에 붙임. 체인점은 상표 대신 업종 이름, 개인 가게는 실제 이름. 가게가 없는 건물은 눌러도 이름표가 뜨지 않고 뒤의 길로 걸어감
- 일하기: 가게 안으로 들어가 사라지고 위쪽에 '일하는 중'. 아무 데나 누르면 그만두고 나옴
- 거리 가게: 편의점·약국·식당·카페에서 회복 물건 사기 (효과는 숫자 대신 '조금 회복·많이 회복' 같은 말)
- 숫자 숨김: 싸움 피해 숫자, 체력 숫자 없음. 체력 막대로만 짐작
- 영격 창: 힘·민첩·생명력·신앙 (각 1에서 시작, 영격이 오를 때마다 2점). 공격력·방어력은 보이지 않음
- 공격 태세: 오른쪽 아래 칼 단추 1번 = 적대 대상만, 2번 = 모두. 손 단추 = 평소대로 (누르면 메뉴)
- 대식자: 범죄 표시 중이면 바늘과 금실을 든 집행자가 다가옴. 체력이 절반 아래로 떨어지면 실밥이 터진 모습으로 변함
- 방어구가 몸에 보임 (헬멧·재킷·조끼·장갑·작업 바지·정강이 보호대·부츠)
- BTS 고가 상판: 기둥 사이를 잇고, 선로가 휘는 곳은 기울여 매끈하게
- 종교 건물: 이름으로 가려 태국 사원(붉은 2단 지붕)·교회(회색 박공과 종탑)·이슬람 사원(초록 돔과 첨탑)·시크 사원(흰 돔과 금빛 작은 돔)
- 오토바이 택시·자동차 바퀴가 바닥에 눕던 문제 수정 (Blender 변환 행렬이 늦게 갱신되던 것)
- 우주새 진열장 조명 밝게
- 비회원으로 바로 플레이. 오른쪽 위 메뉴 왼쪽의 '이 세상에서 살기로 결정' = 가입 (아이디·비밀번호만, 이메일은 나중에)
- 처음 가게를 나선 뒤 거리에서 5분이 지나면 미스 황의 전화 → 예 = 가입·홈 화면 설치 안내 (`?call` 이면 5초)
- 계정 저장: Supabase (아이디·비밀번호 해시·저장 데이터·프로필·신고). 가입하면 기기 저장을 서버로 옮기고 20초마다·창을 닫을 때 저장
- 실시간: 같은 구역의 다른 플레이어가 보임 (Supabase Realtime presence + broadcast). 다른 플레이어를 누르면 프로필 보기·신고
- 관리자 `/admin`: 미스 황·앵무새의 게임 속 도트 그림 교체 칸 (투명 PNG 그대로 올림, 발 = 그림 아래 가운데)
- 홈 화면 설치(PWA): 그림과 지도는 기기에 남겨 다음부터 빨리 엶

### 1단계-A (입구)


- 리니지 초기 크기: 어른 키 약 40px(아이 약 28px), 3/4 시점 대각선 4방향(좌우 뒤집기), 걷기 4장면. 차는 약 30px, 건물 1층은 사람보다 높게
- 첫 장면은 우주새 상점 안 (거리와 같은 축척). 물건은 카운터 뒤, 미스 황 뒤쪽 진열장에 입체로 진열 (상자·캔·병·봉지·밧줄·헬멧·옷·신발), 무기는 카운터 뒤 벽 걸이판, 마네킹, 창 아래 의자·화분·우산꽂이
- 처음 모습은 무작위: 우비(얼굴 가려짐) · 환자복과 머리 붕대 · 남성 · 여성 · 아이 · 앵무새 옷, 드물게(3%) 광채가 일렁이는 남성·여성
- 미스 황은 처음 모습을 보고 한마디 함. 무기와 방어구는 첫 방문부터 살 수 있음
- 문으로 나가면 "…나는 누구였지." 혼잣말 뒤 이번 생의 모습(성별·체격·피부·헤어·머리색·옷·차림)과 지역(방콕 · 수쿰빗 / 서울 · 강남 준비 중)을 고름. 아이로 왔어도 거리로 나가는 몸은 어른, 광채는 남음
- 거리의 우주새 건물에는 간판이 없음. 건물을 누르면 '우주새 상점' 이름표가 뜨고 걸어 들어감
- 대화: 주요 인물은 일본 RPG식 인물 그림, 혼잣말은 이름표 없이 기울인 글씨
- 관리자 페이지 `/admin`: 주요 인물 7칸 그림 교체 (Vercel Blob)
- 시험용 주소: `?newlife` 새 영혼으로 다시 시작, `?form=raincoat|patient|man|woman|child|parrot|auraMan|auraWoman` 처음 모습 고정, `?hour=21` 시각
- 공용 규칙 코드: 카르마 판정, 행위별 점수표, 영격 곡선(800 × n^1.7), 기적 확률, 위험 상태와 차량 충돌

### 1단계-B (현실 생존) — 이번에 들어간 것

- 걷는 모습: 몸통·다리·팔이 모두 걷는 방향으로 같이 돌아감 (가까운 쪽 크게, 먼 쪽 어둡고 작게)
- 건물 깊이: 건물을 32px 세로 띠로 잘라 띠마다 앞뒤를 따로 계산. 건물 바닥 칸은 못 걸음. 캐릭터가 건물·기둥 뒤에 가려지면 그 부분만 반투명
- 간판: 그냥 '상점' 대신 칸마다 다른 이름 (예: 할머니 잡화점, 골목 약국). 한국어·태국어·영어 각각 어순에 맞게
- 내 캐릭터 표시: 발밑 금색 고리와 머리 위 화살표 (범죄 표시 중엔 빨강)
- 대상 메뉴: 사람을 누르면 말 걸기 · 살펴보기 · 강제 공격, 불량배는 공격하기. Ctrl/Shift/⌘ + 클릭 = 메뉴 없이 강제 공격. 이름 있는 가게는 들어가기·일하기
- 싸움: 체력 막대, 치명타, 쓰러짐. 불량배는 밤에 더 멀리서 덤빔. 행인을 먼저 치면 악행 + 3분간 빨간 표시, 행인은 도망치며 소리침
- 돈: 쓰러진 사람이 떨어뜨린 돈을 주움 (행인 돈을 주우면 강도 악행). 일하기 = 방콕 최저임금 하루 ฿400 ÷ 8시간 = 시급 ฿50, 현실 시간으로 지급
- 차 사고: 차는 사람 앞에서 브레이크. 그래도 치이면 체력 30% 손해, 위험 상태(25% 이하)면 사망
- 죽음: 사인 → 이번 생의 선행·악행 → 판정(천국 / 지옥 n층 / 떠도는 영혼). 천국·지옥 문은 아직 닫혀 있어 우주새에서 새 모습으로 눈뜸. 영격은 유지
- 가방: 먹기·쓰기(체력 회복), 장착·빼기(공격·방어), 권총은 총알이 있을 때만 원거리
- 알림: 선행·악행·영혼 경험치·영격 상승
- 저장: 이 기기(localStorage)에 4초마다

## 실행

```
cd apps/web
npm install
npm run dev            # 개발 서버
npm run check          # 타입 검사
npm run build          # 배포용 빌드 (dist/)
```

규칙 검증: `node --experimental-strip-types packages/shared/src/rules.test.mjs`

관리자 페이지가 그림을 저장하려면 Vercel 프로젝트에 Blob 저장소를 연결하고(환경변수 `BLOB_READ_WRITE_TOKEN`), 환경변수 `ADMIN_PASSWORD`를 넣어야 합니다.

## 실제 수쿰빗 지도 넣기

1. openstreetmap.org 에서 수쿰빗 구간을 화면에 맞춘 뒤 상단의 '내보내기(Export)' → '내보내기' 버튼으로 `.osm` 파일을 받습니다. (아속~프롬퐁 정도의 작은 범위)
2. `node tools/osm-convert/convert.mjs 받은파일.osm tools/osm-convert/source/bkk-sukhumvit-full.json --id bkk-sukhumvit --tile 3`
3. 변환기는 큰길을 가로축에 맞춰 돌리고, 정부시설을 간판 없는 일반 건물로 바꾸고, 지도 가운데 가게 하나를 우주새로 정합니다. 서울 강남은 `--keep-right` (우측통행).
4. `node tools/osm-convert/split.mjs tools/osm-convert/source/bkk-sukhumvit-full.json apps/web/public/zones` — 대로를 따라 구역으로 자릅니다 (구역 목록은 split.mjs 의 PLAN).
